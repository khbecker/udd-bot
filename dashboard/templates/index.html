What the states mean

  • Synced Identical to Debian, no Ubuntu delta. Nothing to do.
  • Autosync pending No delta and Debian is newer. Handled automatically before DIF.
  • Delta current Ubuntu carries a delta but Debian is not ahead.
  • Merge needed Debian is newer and Ubuntu carries a delta that must be rebased.
  • Sync available Ubuntu packaged this upstream release first and Debian has caught up; the delta can probably be dropped.
  • In proposed The upload already exists. Chase proposed-migration rather than uploading again.
  • Not in devel Absent from the devel series; check whether it was removed.
  • Ubuntu only No Debian counterpart.

The upstream column comes from Debian's watch files and is a separate axis from the Ubuntu/Debian comparison. Muted means the watch data is missing or unreliable — not that the package is fine.
